# 寻迹宋韵 · 开封景区语言景观交互式词云导航系统

> 基于《东京梦华录》的开封景区语言景观调研与数字化活化实践
> 河南大学 · 挑战杯项目

## 在线访问

**https://wy050105.github.io/xunji-songyun/**

打开后点击地图上的景区圆点即可开始浏览（长卷 / 语料库 / 词云 / 六大类 / 梦华通关文牒）。

## 离线使用

仓库中的 `index.html` 是**单文件自包含**网站：点击该文件 → 右上角 Download 按钮下载，用任意浏览器打开即可，无需联网、无需安装任何东西。

## 技术特点

- 单文件 HTML（约 110KB），零依赖、零构建、零后端
- 内含开封十景完整词库、《东京梦华录》金句、汴京手绘 SVG 地图与长卷
- 桌面 / 平板 / 手机全适配
